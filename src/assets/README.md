# Fotos vom Zum Anker

Lege die echten Fotos mit **exakt diesen Dateinamen** in diesen Ordner
(`src/assets/`). Sobald eine Datei vorhanden ist, nutzt die Website sie
automatisch — fehlt sie, wird ein Platzhalterbild angezeigt. JPG oder PNG.
